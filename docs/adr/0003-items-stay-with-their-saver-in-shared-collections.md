# Items stay with their saver in a shared collection

A shared collection holds items that still belong to the people who saved them. Filing an item into a shared collection does not copy it or hand it over. The Creator and Collaborators see it only while that collection is open, and only its saver can edit or delete it. Anyone in the collection may take it out. Others cannot file it into any other collection. When a Collaborator leaves or is removed, their items leave the collection with them. Every item keeps exactly one saver, so "a stash belongs to one person" (PRODUCT.md principle 4) still holds everywhere except inside a shared collection. Nothing in someone's stash changes behind their back.

## Considered Options

- **Copy per person:** each person gets their own copy and edits it freely. Copies drift apart, duplicates pile up, and there is no single item to take out of the collection.
- **Items owned by the collection:** an item would have no single saver. That breaks the rule every item query relies on, and it leaves no clear owner for the item when the collection is deleted.
- **Anyone in the collection edits any item:** this changes someone's own stash without asking them.

## Consequences

A Collaborator who wants to keep something beyond the collection must save it again. "Save a copy" is left for later. Stash-wide search and the full list show only your own items, so another person's item is found only from inside the shared collection.
